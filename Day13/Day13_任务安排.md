## 一、二叉树是什么？

每个节点最多有两个子节点（左/右）：

```
        1          ← 根节点 (root)
       / \
      2   3        ← 1 的左孩子是 2，右孩子是 3
     / \   \
    4   5   6      ← 叶子节点：4, 5, 6（没有孩子）
```

### 基本术语

| 术语 | 含义 |
|------|------|
| 根 (root) | 最顶层的节点 |
| 叶子 (leaf) | 没有子节点的节点 |
| 父/子 | 直接上下层关系 |
| 深度 (depth) | 从根到该节点的边数 |
| 高度 (height) | 从该节点到最远叶子的边数 |

### TreeNode 定义

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 二、深度优先遍历（DFS）

DFS 沿着一条路走到底再回溯。根据访问根的顺序分三种：

```
        1
       / \
      2   3
     / \
    4   5

前序 (根左右): 1 → 2 → 4 → 5 → 3
中序 (左根右): 4 → 2 → 5 → 1 → 3
后序 (左右根): 4 → 5 → 2 → 3 → 1
```

### 记忆口诀

| 遍历 | 顺序 | 口诀 | 用途 |
|------|------|------|------|
| 前序 | 根→左→右 | 先看老大 | 复制树、序列化 |
| 中序 | 左→根→右 | 从左往右扫 | **BST 得到有序序列** |
| 后序 | 左→右→根 | 孩子看完再看爹 | 删除树、计算子树 |

### 递归实现（核心思想）

三种遍历的递归代码**结构完全一样**，只有 `result.append(root.val)` 的位置不同：

```
def dfs(root):
    if not root: return          # 基线条件
    result.append(root.val)      # 放这里 = 前序
    dfs(root.left)               # 递归左子树
    result.append(root.val)      # 放这里 = 中序
    dfs(root.right)              # 递归右子树
    result.append(root.val)      # 放这里 = 后序
```

## 三、广度优先遍历（BFS）= 层序遍历

一层一层地访问，用**队列**实现：

```
        1
       / \
      2   3
     / \
    4   5

层序: [[1], [2, 3], [4, 5]]
```

### 队列是怎么工作的

```
初始：队列 = [1]
第1轮：弹出1，加入1的孩子 → 队列 = [2, 3]，本层结果 = [1]
第2轮：弹出2，加入孩子4,5 → 队列 = [3, 4, 5]；弹出3，无孩子 → 队列 = [4, 5]
       本层结果 = [2, 3]
第3轮：弹出4,5，无孩子 → 队列 = []，本层结果 = [4, 5]
```

### 关键点
- 用 `collections.deque` 做队列（`popleft()` O(1)）
- 每层要知道当前层有几个节点（`for _ in range(len(queue))`）
- DFS vs BFS：DFS 用栈（递归隐式栈），BFS 用队列

## 四、二叉搜索树（BST）

BST 的规则很简单：**左 < 根 < 右**（所有左子树节点 < 根 < 所有右子树节点）。

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \
      4   7
```

### BST 查找 — O(h)，h 为树高

```
找 7：8>7 往左 → 3<7 往右 → 6<7 往右 → 找到7
找 9：8<9 往右 → 10>9 往左 → 空，不存在
```

每次砍掉一半子树，类似二分查找，**前提是树平衡**。

### BST 插入 — O(h)

```
插入 5：8>5 往左 → 3<5 往右 → 6>5 往左 → 4<5 往右 → 空位，插入
```

6. 实现 `bst_insert(root, val)` → 插入后返回根节点
